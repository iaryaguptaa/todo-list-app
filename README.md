## To-Do List App

A simple **Python To-Do List App** built using **Google Colab**.  
This project helps you add, view, update, and delete your daily tasks — perfect for beginners in Python programming.

## Features
-  Add new tasks  
-  Mark tasks as complete  
-  Delete tasks  
-  Automatically saves tasks in memory while running

##  Tech Stack
- Python 3  
- Google Colab (for running code)  

---

##  How to Run
1. Open this project in **Google Colab**  
2. Copy the code from `to_do_list.py`  
3. Run the code cells one by one  
4. Start managing your tasks easily!
